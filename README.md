# Grafyla — setup

The setup page of Grafyla, and its counter — the way without a copy of the engine (the engine's
`docs/DESIGN_PHASE3.md` §5a). The page (`page/`) is served by GitHub Pages at `https://setup.grafyla.com/page/`; the
counter (`counter/`) has run on the owner's Cloudflare account since 19.11.2026. The rules a person's AI reads are in
`grafyla/releases`. Until 23.11.2026 this repository was `Garik98129/memory-engine-install`. License: MIT (`LICENSE`).
